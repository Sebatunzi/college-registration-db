5. Implementation & checksThe schema was built and tested in SQL (sql/01_schema.sql)

CREATE TABLE registration (
  registration_id   INT         NOT NULL,
  student_id        INT         NOT NULL,
  course_id         INT         NOT NULL,
  academic_year     CHAR(9)     NOT NULL,
  semester_no       SMALLINT    NOT NULL,
  registration_date DATE        NOT NULL,
  status            VARCHAR(15) NOT NULL,
  final_grade       VARCHAR(2)  NULL,
  PRIMARY KEY (registration_id),
  UNIQUE (student_id, course_id,
          academic_year, semester_no),
  FOREIGN KEY (student_id)
    REFERENCES student (student_id),
  FOREIGN KEY (course_id)
    REFERENCES course (course_id)
);

Tests run against the database:

  • Duplicate registration in the same semester: rejected
  • Registration for a non-existent student: rejected
  • Invalid gender value: rejected
  • Grade on a registration that is not Completed: rejected
  • Deleting a department that still has programmes: rejected
  • Courses outside the student's programme: 0 rows

Normalised to 3NF: no repeating groups and no partial or transitive dependencies.
